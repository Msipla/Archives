# 《艾瑟兰德：剑与魔法》· 世界细纲

> 本文件配合 [Archives 跑团总纲](../TRPG_RULES.md) 使用，记录本世界**已经确认的主持与存档约定**，不替代 [最新权威存档](canonical-save.md)，不在这里维护当前日期、HP、金钱、装备版本或下一回复编号。

## 玩法与叙事

- 玩家角色始终写作 **Mispla**，不音译；他在《艾瑟兰德》的身份与《渊城》的同名角色完全独立。
- 玩家控制 Mispla 的台词、行动、重大选择和情感；GM 主持 NPC、世界事件与后果。NPC 有独立日程，世界不因主角不关注而停止，但**不强制主线、不强制背叛、阴谋或家族复兴**。
- 风格以原创奇幻、冒险、探索、魔导工艺、学院与生活、人物关系及奇观为主；**少强烈恐怖与持续压迫**。场外作品类比不自动成为世界内作品、技能或事实。
- 现行世界定位为**魔导文明的便利程度 + 古典王国与冒险者社会形态**；具体世界设定以[世界观定稿](reference/06_魔导文明与生活经济_定稿_v1.md)及已发生剧情为准。

## 掷骰与机制

- **所有 PC 骰由玩家亲自掷**，GM 不代掷；GM 可掷 NPC 骰。
- GM 在玩家掷骰**之前**明确检定种类、DC/对抗值、加值与主要失败风险；自然20攻击按已定暴击处理，但技能检定不自动成功。
- 战斗遵守已确认的动作、附赠动作、移动与反应经济。**不得为了华丽叙事免费追加攻击、技能或 MP**。已经学会但动作经济尚未明确的能力保留为 **OPEN**，先公开裁定再使用，不擅自删掉既有能力或创造新机制。
- 装备数值、战技、HP/MP、资源、XP、金币与未决规则均从**最新权威存档当前章节**读取；历史审计中的数值只是历史快照。遇到争议查[规则财务审计](reference/04_规则_财务_冲突审计.md)和实际战斗记录。

## 周期计数与真实归档

- 每条**真正推进剧情的 GM 回复**在游戏日期时间之后标注本周期编号 `（N）`；纯场外讨论不计数，不凭估算补号。
- 每周期 **20 条**剧情 GM 回复；第 `（20）` 条完成时，**当次实际生成、保存、校验可跨窗口迁移的完整存档**，再从新周期 `（1）` 开始，绝不写 `（21）`。若工具暂时不可用，明确报告未完成归档，不谎称已保存。
- 重大事件、关键交易、重要人物关系变化、章节结束或升级时，按需要**即时增量存档/全面审计**；这些记录不擅自重置正常周期计数。
- 完整存档至少覆盖：准确游戏内日期时间与暂停点、下一条回复编号、完整角色卡、技能与动作经济、装备与消耗品、现金与未结账目、NPC关系与各自所知、任务及世界事件、玩家明确纠错、重要骰点、已定世界设定和 OPEN/CONFLICT。
- `history/cycles/` 新增原始周期记录，旧文件保留；`canonical-save.md` 负责当前权威状态。提交 GitHub 后**核验真实存在并告知提交编号**。未满20条就换窗口时，先制作可靠的中途快照或核对尚未同步的剧情。
- 新窗口按 [HANDOFF.md](HANDOFF.md) 恢复，**先汇报、等玩家确认，不自行推进**。历史资料中的“下一条”“当前余额”“暂停点”均不得覆盖最新已确认事实。

## 未解决规则的处理

若发现经验升级制度、战技启动动作、现金流水或 NPC 能力存在缺口：**标记 OPEN，保留已发生结果，必要时暂停该项判定并请玩家裁定**。不要把过去的争议暗中写成已定规则。

> 这是稳定细纲，不是剧情日志。未来仅在玩家明确改变玩法约定时修改；普通剧情推进只更新权威存档。
