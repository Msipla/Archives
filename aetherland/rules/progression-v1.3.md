# 艾瑟兰德成长规则 v1.3（玩家2026-10-12批准）
- 20级累计XP制，沿用D&D5e XP阈值与熟练加值：Lv3 900，Lv4 2700，Lv5 6500，Lv10 64000，Lv15 165000，Lv20 355000；完整阈值按5e。
- 当前Lv3初始化900累计XP，历史已完成成果一次性补发：10月18日幻影剑循环型研发掌握+600；11月19日长刀风雷改MkIII传导弹芯技术验证+200；11月28日双形态长镰研发与测试+350；11月30日短刀强化验收+100；共+1250，规则启用时累计2150/2700，距Lv4 550；后续已结算XP以[权威存档](../canonical-save.md)为准。此为新制度启用结算，不代表历史全部XP重新计算，不重复发放。
- 玩家每次升级自行投1d8生命骰，最大HP增1d8+体质修正（至少1）；最大MP+2；体质修正变化时最大HP按角色等级追溯差额。旧Lv3 HP24 MP10保留，不追溯掷骰。
- Lv4/8/12/16/19选择单项属性+2或不同两项各+1，通常上限20；熟练加值按5e等级表。
- Lv5/10/15/20是瓶颈：XP达到门槛后仍可积累、不会丢失；须通过玩家选择的真实训练、研究、冒险或战法突破才升级。突破不绑定固定职业分支、任务或Boss；允许兼修与自创流派。突破不能凭空产生额外行动、无穷伤害等，特征须逐项讨论和平衡。
- 日常训练与研究有成长价值，XP在阶段成果时集中结算，不按每一天或聊天条数刷XP；Lv3附近参考：有效训练/小研究突破100-200，探索交涉战术150-350，普通C级委托400-700，高难C级委托700-1100，重大剑术魔导研发400-800，大型篇章1000-1800。同一成果不得重复结算；高等级按挑战调整；每次明确原因、变化、累计和下级差额。
- XP在当前聊天内即时记录；每20条GM剧情回复归档到GitHub，升级、突破、跨窗口等关键节点提前同步。无法确认临时账本时必须查档，不得猜。
