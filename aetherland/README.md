## 欢迎来到艾瑟兰德

这是一个持续进行中的西方奇幻跑团世界。魔导技术改变了城市生活，通讯与日常服务可以借助魔法实现；与此同时，王国、骑士、工匠、公会与冒险者依然是社会的重要部分。

艾瑟兰德不是只有一条主线的关卡地图。人物有自己的生活、职业、选择与关系。冒险之外，还有庄园、工坊、研究、训练，以及一个年轻人逐渐建立起来的归属。

## 故事从谁开始？

**Mispla · 维尔哈特**，二十岁，人类，没落贵族出身。当前归档记录中，他是一名 **Lv3 魔导剑士（迅刃流）、C级冒险者**。他擅长长刀与短刀，也在探索风、雷和魔导技艺如何融入自己的战斗方式。

围绕他展开的生活中，有独立魔法研究员**伊薇特·罗兰**、庄园管家**玛莎·贝伦**、工匠**布罗姆**、剑术导师**奥伦**，以及冒险伙伴**加伦、莉娅和托马斯**等人。

这里的角色并非只为主角提供任务：他们各自拥有职业、判断与生活。
