# 艾瑟兰德 · 跨聊天 GM 交接指南

> **先读 [总纲](../TRPG_RULES.md) 与 [本世界细纲](RULES.md)。** 本文件是恢复入口，不是状态快照。 本文件只规定恢复顺序、权威来源与归档规则。**不在这里固定游戏日期、场景、HP、金钱或周期编号。** 每次接续都必须读取 [最新权威存档](canonical-save.md)；不要把历史摘要当成今天的进度。

## 新窗口恢复流程

1. 打开本仓库 **main 分支最新版本**的 [canonical-save.md](canonical-save.md)，并核对[周期原始记录](history/cycles/)中游戏日期更晚的已归档记录。先读文首增量，再读第0—4章；章节名写“最新”不代表时间真的最新。若最新周期已入库而整合存档尚未同步，明确报告差异并按第4步等待玩家确认，不能从旧暂停点倒退或凭摘要自行合并战斗状态。**不要沿用旧聊天记忆里的暂停点。**
2. 必要时交叉核对 [世界观定稿](reference/06_魔导文明与生活经济_定稿_v1.md)、[NPC 关系](reference/03_NPC_关系_历史线索.md)、[规则财务审计](reference/04_规则_财务_冲突审计.md)及[周期原始记录](history/cycles/)；不得让旧资料里的“当前”覆盖最新状态。
3. 权威优先级：**玩家最新明确裁定和实际发生的剧情 > 最新权威存档的当前章节 > 已确认世界观定稿 > 对应时间的原始记录 > 历史摘要与审计**。若新聊天已发生但尚未提交 GitHub 的剧情存在，应先请玩家提供该段可靠记录，核对后再续；**不能因为仓库较旧就把已发生剧情判作不存在**。
4. **先向玩家汇报**已核实的游戏日期、地点、角色状态、重要人物关系、未解决事项、下一条 GM 回复的准确周期编号和证据来源，**等待玩家确认**；不要自行推进剧情或重置进度。
5. 具体掷骰、行动经济、周期计数与归档规则以[本世界细纲](RULES.md)为准。若已在新窗口续团，计数以实际连续剧情记录为准，不可凭推测补号。

## 每次正式归档时

- 在 `history/cycles/` **新增**该周期原始存档，保留旧周期，不覆盖已有历史。
- 核实新记录与已有正史的连续性，再更新 `canonical-save.md` 的当前章节，包括**准确暂停点、角色资源、NPC 关系、已发生事件、未决事项和下一条回复编号**。没有证据的数值保持未知，不要编造。
- 实际提交到 GitHub，核验新文件存在、最新权威存档已更新，并告知玩家提交编号。**只在确有变动时**更新世界设定或审计；本交接指南无需每周期重写。
- 如果周期尚未达到归档节点却需要换窗口，应先制作并验证**临时完整续团快照**，或由玩家提供该段新剧情记录；明确标注其时间和与现有权威存档的关系，避免从旧锚点重复开始。确认无误后才将新状态并入权威存档。
