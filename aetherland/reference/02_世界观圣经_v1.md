# 艾瑟兰德世界观圣经 v1.0

## 核心基调 CANON（2026-10-10玩家明确确认）
> **B的文明特征，A的社会形态**：魔法与魔导工业高度普及，普通人可享有类似现实成熟技术社会的生活便利；但政治、审美与社会结构仍有贵族、骑士团、古老剑术流派、冒险者公会、城堡、学院、王国等古典英雄奇幻气质。参考《星球大战》的“先进文明+古老传奇”感受，但**星战不属于游戏内知识**。

> **神奇可以日常，奇迹仍是奇迹。** 居民习惯多智慧种族、魔法服务、浮空设施；面对传奇剑圣、超越理论的巨构、未知魔法现象，仍然惊叹。未知领域广阔，故事多冒险与壮丽探索，少恐怖、少强制邪恶。

## 已确立的生活常识 CANON
- 大城市中，民用**语音通讯晶石**常见且相对亲民，依赖魔导通讯塔中继；偏远地区覆盖差，远距加密高阶设备更昂贵。**Mispla此前并未自动拥有私人通讯晶石**。
- 公会与学院可机构语音转接；公会牌价城内文字传讯2铜/条、机构转讯5铜/次（已在剧情展示）。
- 魔导工业、飞舟/浮空岛、学院与公会、魔法研究与产业链存在。制式零件和批量制造可以经济；Mispla装备升级昂贵是**定制试制、特殊兼容和工匠工时**，不表示所有魔导器具都稀有。
- 各智慧种族不仅是魔物，也可以是居民、商人、服务者、研究者与冒险者；种族不预设道德。魅魔经营餐饮或娱乐业等是**世界风貌允许的正常可能**，但**具体店铺、位置、营业项目和NPC仍待游戏中确立**。
- 魔导枪械与传统冷兵器可以共存；魔法、肉体强化、战技使刀枪剑戟斧钺等拥有超越现实的战术价值；枪械不被强行削成无效，具体平衡遵守规则。
- 古典社会制度与便利的魔导生产力并存，但不简单复制现代手机、汽车、互联网的全部制度；魔法有自身资源、限制、基础设施和文化。
- 城市繁荣与荒野危险并存；交通、医疗、通讯均有成本与边界，强力传送、复活等不应无代价普及。

## 已知地理/历史 CANON
- 世界：艾瑟兰德；莱恩王国、阿尔维恩城、王立魔法学院、维尔哈特庄园、灰岩矿坑等已出现。具体大陆地图、国家分布、人口统计**OPEN**。
- 维尔哈特家族约百年前靠魔导器材和军需贸易兴起，受大型工坊竞争及贸易变迁而衰落；父母已故，非默认诅咒/复仇线。
- 世界已有浮空岛、飞舟与魔法痕迹；**不能倒推所有城镇都有同等设施或相同物价**。

## 合理但未锁定的扩展 PROPOSAL
- 量产民用通讯晶石的规格、价格区间、充能/资费、个人印记和隐私法规。
- 公交、魔导车、魔导列车、空岛航线及道路网络的具体覆盖；Mispla此前主要步行/公共交通是玩家提出的**解释方向**，不应倒填未发生的乘车事件。
- 多智慧种族公民身份、职业、跨种族婚姻、学校与行业规范；魅魔咖啡店/风俗行业是可能的文化场景，不自动断言Mispla曾去过。
- 魔导武器量产与定制价格体系、能源来源、机械加工能力；枪械与剑术流派战术生态。
- 传奇力量、禁咒、魔法宇宙学、地脉、巨构和未知地区：只锁定“存在未知与奇迹”，不提前定死具体答案。

## 创作与叙事禁忌
1. 不因世界观补丁追溯推翻已发生剧情、关系、战斗、装备、金钱与检定。
2. 不以“没钱”解释所有未接触内容：生活圈、兴趣、地理、交通和时间同样重要。
3. 不把异种族都写成怪物，也不把所有异种族写成善良无害。
4. 不让NPC引用用户场外提过的《星球大战》《鬼泣》《只狼》等现实作品。
5. 不将世界观写成静态百科全书：保留未发现的区域和NPC自己的生活。
