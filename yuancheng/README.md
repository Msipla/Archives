> **独立世界：渊城**。与《艾瑟兰德：剑与魔法》无剧情、角色卡或规则上的继承关系。两个世界中都存在名为 Mispla 的角色，但并非同一条人生。

- [《渊城：关系之神》——实际跑团正史小说](stories/relation-god.md)：面向朋友的第一人称文学改写，保留关键经历与结局。

- [连续性与小说改写说明](continuity.md)：区分跑团事实、文学补白和原案假设。

## 本世界目前状态

第一部冒险已经结束。Mispla 原为二十岁铜牌神秘学冒险者，后来完成活体跨载体连续性转移，仍坚持以人类经历为自我根基。NODE-01 是独立主体；伊蕾娜是可靠的见证者；白的来历仍有未解之处。北方遗迹的异常已停止扩展并观察到回退，但世界远未被彻底解释。

**阅读提醒：** 正史小说含第一部结局剧透；原案小说含大量为了完成平行故事而新写的情节。若要在新聊天中继续实际跑团，不能以小说代替正式GM存档。
