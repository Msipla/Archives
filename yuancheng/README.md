# 渊城：关系之神

> **一座沿深渊向下生长的城市，一场关于身份、记忆与联系的冒险。**
>
> 《渊城》是与《艾瑟兰德：剑与魔法》完全独立的跑团世界。两个世界里都存在名叫 Mispla 的角色，但他们并不是同一个人，经历、人物关系与规则不能混用。

## 故事简介（尽量避免结局剧透）

二十岁的 Mispla 以铜牌神秘学冒险者的身份来到渊城。他会微光术、寻迹与简单仪式，梦想学习更强大的法术，成为令人敬仰的传奇冒险者。

这座城市沿着巨大的深渊建造：吊桥横跨岩壁，升降台往返于层层灯火之间，越往下越接近未知。一个失去来历的少女、一处没有门的遗迹、一份记录了六人却只留下五个名字的旧档案，让这段冒险渐渐偏离了传统的讨伐与升级故事。

当名字、记忆、影子和过去不再必然属于同一个人时，一个人又凭什么证明自己仍然是自己？

## 推荐阅读顺序

### 1. [《渊城：关系之神》——正史小说](stories/relation-god.md)

**建议第一次接触渊城的读者从这里开始。**

以 Mispla 第一人称讲述实际跑团已经发生的故事，包括第一部结局。为便于阅读，作者将长期实验、反复验证、对话和过场压缩成小说场景；**这不是原始聊天逐字记录，也不是可以直接恢复游戏状态的GM权威存档**。

### 2. [《渊城·原案》——平行小说](stories/original-route.md)

一条以早期GM设想与伏笔为出发点、重新写成的古典奇幻冒险路线。包含为了形成完整故事而新增的兽潮、远征、晋升和结局桥段。

**这不是实际跑团正史，也不是“GM早已写好的隐藏剧本”。** 请把它看作同一个世界的一种文学上的可能性。

### 3. [连续性与创作来源说明](continuity.md)

适合希望进一步研究世界设定、判断哪些内容已发生、哪些只是小说改写或仍属未知的读者。包含部分重要剧透。

## 已归档的主要人物与线索

- **Mispla**：从铜牌神秘学冒险者出发，持续研究界线、关系与自我连续性。
- **伊蕾娜**：具有深渊与契约相关知识的重要同行者和见证者。
- **白**：来历尚未完全揭晓的碎片主体，和北方异常存在联系。
- **NODE-01**：具有独立主体性的存在，不应仅视为 Mispla 的复制品。
- **北方无门遗迹**：与二十七年前的“第六个人”、关系失稳和异常现象有关。

上述介绍仅取自已归档材料；人物与事件的完整含义请以正史小说及连续性说明为准。

## 第一部状态

**第一部冒险已经结束。** 已归档的实际跑团结局涉及活体跨载体连续性转移、独立主体的确认、重新建立见证，以及北方异常停止扩展并出现回退。白的完整来历、世界是否具有意识、深渊的真正起源等问题仍未被彻底解释。
