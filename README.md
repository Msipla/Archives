## 推荐怎样阅读？

**第一次来：** 打开[档案馆网站](https://msipla.github.io/Archives/)，选择感兴趣的世界，先读世界简介，再读人物与故事。

**想了解故事背后的设定：** 各世界的 README 会引导你进入世界观、人物资料、原始档案和创作说明。

**想继续跑团或核对细节：** 不要直接把小说改写当作游戏状态存档。《艾瑟兰德》请先读[跨聊天GM交接入口](aetherland/HANDOFF.md)，再以[最新权威存档](aetherland/canonical-save.md)为恢复依据；《渊城》当前上传的是文学改写和连续性说明，尚不能代替完整GM状态存档。

## 这个档案馆如何维护？

- **一个世界，一个目录。** 新世界不覆盖旧世界。
- **正史与创作分开。** 已发生剧情、文学改写、平行路线、废案和未解谜团应明确标注。
- **原始记录与读者导览分开。** 读者可以轻松进入故事，研究者仍能追溯来源。
- **不擅自补完。** 没有确认的设定就保持未知；旧版状态不能覆盖新版本。
- **更新必须真正提交 GitHub。** 网站可以尝试自动发现新增 Markdown 文件，但不能凭空从聊天里同步内容。
- **公开仓库不等于私密存档。** 不应上传需要保密的私人信息或GM秘密；网页的剧透提示不具备访问控制能力。
